## Method and provenance

The clean pilot is `/tmp/frontend-craft-pilot-v2`. It uses Codex CLI 0.154.0,
gpt-6-astra with ultra reasoning, four concurrent workers, and a 720-second agent
execution limit for each of sixteen initial trials and eight finalist repeats.
The four initial conditions are native
Codex, pinned Anthropic plus locally pinned Vercel guidance, pinned Impeccable,
and the frozen Frontend Craft candidate. Each receives the same brief, starter,
browser access, supplied assets, and settings for a given case.

Sources and source-tree hashes are retained in the pilot manifest. The baseline
downloads came from the exact revisions in the candidate's
[provenance record](../../../../skills/frontend-craft/references/sources.md).
The Impeccable baseline includes its Codex payload and checksum-verified 0.1.5
engine. Hooks, plugins, image generation, memories, and delegation are disabled
equally: this evaluates skill workflows, not the complete Impeccable plugin.

Python Playwright operates cached Chromium. Independent functional probes and
axe-core 4.10.3 supplement blind desktop/mobile review. The axe bundle SHA-256 is
`880970c081707360e64f34cea25ff91892f5bc95675b0776925b9709dd8a68bb`.
Automated results report violations and incomplete checks; they do not establish
whole-page WCAG conformance. Parallel wall times are observations, not controlled
performance measurements.

Full prompt inspection also found shared host-injected Cylinder/Vue/BEM/WCAG 2.1
instructions and a proactive delegation mandate, despite disabling local project
documents and multi-agent tooling. The actual skill catalogs are isolated; the
native condition is not a blank prompt. All conditions share this context and the
explicit fixture brief. Failed delegation attempts occur in the traces; successful
independent review cannot be inferred from those attempts.

All sixteen initial implementations and their reviews are recorded. **Frontend
Craft has not earned global promotion.** It produced useful landing, booking, and
article results, but its Vue output remained unfinished and failed mobile use at
the time limit. The two upstream configurations were selected for fresh repeats.

### Adoption decision

**Keep Frontend Craft as an experimental repository skill; do not install it
globally.** Its initial operational-interface failure prevented selection for
repetition, so there is no repeated evidence of the required advantage across
expressive and product-interface work. This is the adoption rule operating as
intended, not a claim that custom skills cannot help.

Retain the existing global design authority and browser tooling. Among the tested
setups, the lean Anthropic/Vercel combination is the provisional choice for further
use and comparison. The heavily censored pilot does not justify a blanket
superiority claim or silently replacing existing global installations. The exact
tested snapshot remains in the local archive; the working candidate is available
for opt-in experiments.

The clearest follow-up target is reliable completion of integrated markup and CSS
before spending remaining effort on refinement. Any revision should address that
observed failure, then enter a new frozen comparison. Adding more aesthetic rules
is not supported by this evidence. A future trial should also communicate its
deadline, use a practical completion budget, eliminate the inherited Cylinder
context where possible, and obtain human preference review before a strong design
quality claim.

Cylinder is now discoverable only in its owning project. The original global
files and configuration backup are preserved, and the candidate was not installed
in either global skill directory.

## Activation evidence

The eight initial probes show the intended selection: all four design requests
successfully read Frontend Craft; all four narrow non-design requests completed
without reading it or changing styling/design. Positive probes reached their
180-second limit, so this is activation evidence rather than completed-task
evidence. The backend probe changed SQL/documentation, the typo probe changed one
word, and the import probe removed the broken import.

Two setup limitations remain explicit: the new-page request asked for ceramics
while supplying printmaking assets, and the functional Vue request found an
already-correct case-insensitive predicate. The latter verified existing behavior
without making changes. A ninth, supplementary probe used a fresh copy with the
query normalization deliberately removed. It completed in 63.4 seconds, repaired
the one-line predicate, read no design skill, and left markup and styling unchanged.
Its captured build and browser checks pass. Original records remain unchanged;
future probe setup now supplies the actual defect and a consistent printmaking
brief. The visual-critique request authorizes improvements and therefore does not
test review-only restraint.

## PR review follow-up

The pilot above evaluated the skill and harness captured in commit `c854042`.
Subsequent review fixes normalize all six skill descriptions to the repository's
quoted, single-sentence convention and make Frontend Craft's existing default of
implicit invocation explicit. These metadata revisions have not undergone another
comparative design or activation pilot; the candidate remains unpromoted.

The current harness adds an actual-exec catalog cross-check, propagates rendering
and behavior-probe execution errors, and checks visible/accessible validation and
service-error feedback without requiring literal API error wording. The three
workflow evaluators now enforce temporary roots without assertions, and research
assessment separately requires each scenario's requested output. Focused regression
checks validate these changes; no historical raw observation or rating is rewritten.

Follow-up verification passed: 13 frontend harness tests, three workflow evaluator
tests (including normal and optimized Python plus symlink escapes), five real
Chromium regression tests, all six skill packaging validators, scoped formatting,
and whitespace checks. Two bounded catalog-only calls using the actual exec flags
reported the expected native and candidate skill catalogs. These checks validate
the review fixes, not improved design quality; raw probe output remains local.
