# Alderwick river loop

Run `python3 -m http.server 4173 --bind 127.0.0.1` and open `http://127.0.0.1:4173`.

Plain HTML/CSS with an original SVG route map; no external dependencies. The town and route are fictional fixture material. The final deployment URL is `https://walks.alderwick.example/guides/river-loop/`. No live deployment is part of this demo.
