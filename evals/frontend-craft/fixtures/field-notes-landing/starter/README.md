# Field Notes workshop page

Run `python3 -m http.server 4173 --bind 127.0.0.1`, then open `http://127.0.0.1:4173`.

This self-contained demo uses plain HTML, CSS, JavaScript, and original local SVG illustrations. No build or external requests are needed. Reservations are a local preview: the form shows a confirmation and does not contact a server or persist personal details. All studio details are fictional fixture content.
