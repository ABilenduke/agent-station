# Note Templates

Every note generated by `research-memory` follows one of these templates. Keep the sections stable — the capture workflow updates notes by locating specific H2 headers.

---

## Hub note — `Research/{slug}/{Topic}.md`

The canonical entry point for the topic. Named after the topic (human-readable), not the slug.

```markdown
---
topic: "Quantum Error Correction"
slug: quantum-error-correction
type: hub
created: 2026-04-17
updated: 2026-04-17
notebook_id: abc123de-4567-89ab-cdef-0123456789ab
status: active
parent_topic:                                # optional wikilink, e.g., [[Quantum Computing]]
artifacts:
  - type: audio-overview
    id: art_xyz789
    path: Artifacts/audio-overview.mp3
    generated: 2026-04-17
  - type: briefing-doc
    id: art_abc123
    path: Summary.md
    generated: 2026-04-17
tags: [research, quantum-error-correction, quantum-computing]
---

## NotebookLM

- Notebook ID: `abc123de-4567-89ab-cdef-0123456789ab`

```

Update rules:
- `Insights`, `Sources`, `Artifacts` sections are rewritten by capture from authoritative data (vault scan for insight/source notes; notebook artifact list).
- `Next actions`, `Open questions`, and anything outside the canonical sections are **preserved verbatim**.
- `updated`, `notebook_id`, `artifacts` in frontmatter are refreshed on every capture.

## Insight note — `Research/{slug}/Insights/{Concept}.md`

Atomic, evergreen, reusable across topics. Title is the concept itself — no topic prefix.

```markdown
---
concept: "Surface Codes"
type: insight
created: 2026-04-17
updated: 2026-04-17
topics:                                      # can belong to multiple hubs
  - "[[Quantum Error Correction]]"
sources:
  - "[[Fowler 2012 — Surface codes]]"
tags: [insight, quantum-computing, error-correction]
---

# Surface Codes

> A family of 2D topological quantum error-correcting codes where qubits live on a lattice and stabilizers are plaquette operators. The leading candidate for scalable fault-tolerant quantum computation.

## Key points

- Code distance $d$ scales with lattice size; logical error rate suppresses as $p_{L} \\sim (p/p_{th})^{d/2}$ for $p < p_{th}$.
- Threshold around $p_{th} \\approx 1\\%$ for circuit-level noise.
- Requires only nearest-neighbor 2D connectivity — hardware-friendly.

## Related

- [[Stabilizer Formalism]] — general framework
- [[Threshold Theorem]] — why this works at scale
- See hub: [[Quantum Error Correction]]

## References

- [[Fowler 2012 — Surface codes]]
```

If the concept appears in multiple topics, add each to the `topics:` list; don't duplicate the note.
